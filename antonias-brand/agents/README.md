# 🍕 فريق Antonia's — 10 Agents احترافيين لـ Claude Code

10 وكلاء حقيقيين بصيغة Claude Code Subagents، مبنيين بمعيار مستودع ECC نفسه، وجاهزين للتشغيل فوراً.

## وين الملفات؟
- **الأصل:** `antonias-brand/agents/*.md`
- **مثبّتين للتشغيل:** `.claude/agents/*.md` (Claude Code بيقرأهم تلقائياً من هنا)
- لتشغيلهم بأي مشروع تاني: انسخ ملفات `.md` إلى `~/.claude/agents/` (عالمي) أو `.claude/agents/` بمشروعك

## كيف بيشتغلوا؟
بـ Claude Code: كل وكيل بيتفعّل **تلقائياً** حسب وصفه لما المهمة تمر معه، أو طلبه صراحةً:
```
استخدم antonias-qa-director للفحص النهائي
```
كل وكيل فيه: الدور + **قاعدة البيانات المؤكدة** (هواتف، ساعات، أسعار — ممنوع الاختراع) + ملفات المشروع + سير عمل + صيغة مخرجات + قواعد صارمة.

```
① antonias-site-auditor ── الفحص الحي وتحديد المشاكل بالأدلة
```

## القواعد الذهبية (مدمجة بكل وكيل)
1. ولا رقم ولا سعر ولا ساعة من الذاكرة — بس قاعدة البيانات المؤكدة أو فحص حي
2. ممنوع كلمات المرور — منصات مستضافة: خطوات لوحة تحكم + نصوص جاهزة + إيميلات دعم
3. ولا غلطة تمر — الوكيل 10 (opus) بيوقف أي شي مش متأكد منه
4. الاتساق قبل الكمال — كل أصل من عيلة Dark & Golden الوحدة
