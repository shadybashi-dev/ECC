# Off-site SEO checklist — the half that cannot be done from this repo

Everything on-site is shipped and gated (see HANDOFF §10, reference/council-review.md).
Local-pack ranking ("#1 in the region") is decided mostly OFF-site, on assets
only the owner controls. Honest expectation: the site makes Google able to
understand and trust the business; these steps make Google want to rank it.

## Google Business Profile (biggest single lever)
- [ ] Claim/verify both profiles: "Antonia's Pizza" SLO (891 Higuera St) and
      Paso Robles (729 12th St) — separate profiles, exact NAP as on the site.
- [ ] Primary category "Pizza restaurant"; secondary: "Italian restaurant",
      "Pizza Takeout", "Pizza delivery".
- [ ] Hours exactly as on the site (SLO Sun–Wed 11–mid, Thu–Sat 11–2am;
      Paso Sun–Thu 11–mid, Fri–Sat 11–2am). Update holiday hours.
- [ ] Photos: upload the REAL photos from assets/img (real-pep, real-patio,
      real-night, storefronts) — GBP photos feed the local pack directly.
- [ ] Products/Menu section: link to https://antoniaspizza.com/menu and the
      Toast ordering URL; no prices needed.
- [ ] Weekly Google Post (one dish photo + one line) — freshness signal.

## Reviews (the ranking fuel we deliberately did NOT fake on-site)
- [ ] Steady cadence beats bursts: ask happy tables in person (QR on the
      receipt pointing to the GBP review link), never incentivize.
- [ ] Owner-reply to every review, mention the dish and the town by name
      ("glad the Ajarski found you on Higuera St") — reply text is indexable.
- [ ] The site's visible testimonial cards: confirm each quote is a real
      customer review before it stays (integrity check from round 2).

## Citations / NAP consistency
- [ ] Apple Maps, Yelp, TripAdvisor, Bing Places, Facebook — same name,
      same address format, same phones ((805) 439-2383 / (805) 238-1851).
- [ ] Local data aggregators where free: Express Update (Factual feeds
      Apple/Uber/etc.), Yelp for Business.
- [ ] Chamber of commerce + downtown SLO / Paso Robles business associations.

## Local backlinks (authority)
- [ ] SLO Tribune / Paso Robles Press food features; New Times SLO "best of".
- [ ] Cal Poly student org event catering pages; school fundraiser menus.
- [ ] Wine-country tourism lists (Paso Robles Wine Country Alliance).
- [ ] Supplier shout-outs (local farms/dairies that list their accounts).

## Measurement
- [ ] Google Search Console: verify domain, submit sitemap.xml, watch the
      "Pizza san luis obispo" / "pizza paso robles" query pages monthly.
- [ ] GBP insights: direction-requests and calls are the KPI that maps to
      foot traffic, not vanity impressions.

Nothing above can be automated from this repository; the bridge pack and
HANDOFF §10 explain what the site side already guarantees.
