## How to Produce — Pro Tools Workflow (No Invented Facts)

Sandbox has no ffmpeg, only ImageMagick — so above are CSS story players (vanilla only, transform/opacity/filter only, pause+RM, storyCycle0-4 15s/30s, progressBar). For real MP4s, owner uses pro tools with real photos. Never AI-replace storefront.jpg/pies-2.jpg, never generate fake location, never branded bottles (Monini), no marble studio kitchens, no generic dishes. Prompts forbid text/logos/brands/faces, grounded in owner real crops. Toast is only checkout, target=_blank.

**Dreamina (CapCut) — Restaurant workflow:**
Upload real-* photos → image-to-video → choose motion: rising steam, gentle push-in, soft background movement, light reflection, sauce drizzle, parallax, close-up reveal. Turn one dish photo into TikTok teaser, IG Reel, delivery promo, lunch special, seasonal, paid social. Seedance 2.0-powered, multimodal refs, audio workflows.

**Sora 2 + Veo 3.1 — Frontier:**
Via PostEverywhere $9/mo, Canva, Runway. Best for B-roll: clock timelapse midnight→2AM, flour dust, cheese pull macro, butter melting. Use real photos as first frame, then generate motion. Keep brand exact file intact — if typography must stay exact, use Canva not MotionVid (MotionVid re-render can soften).

**Kling 3.0 $6.99/mo — Budget 15s + CapCut free editor:**
Kling 3.0: 66 daily credits free 720p watermarked, 15s clips, best budget generation. CapCut: free editor, beat-synced, captions auto, text kinetic, transitions. OpusClip: long catering testimonial → viral short. Jitter: frame-exact 720p 3 files free. Canva: exact file intact free template. Renderforest: 3D Lite $9 Pro $19 Business $29. MotionVid $19/mo 500 gens $0.038 custom.

**Workflow:**
Real photos (real-pesto, real-box, real-patio, real-night, dough-toss, hero-pep, ajarski-2, pies-1, feast-wide, storefront) → Dreamina/Kling animate (steam, push-in, parallax, drizzle, close-up) → CapCut edit + captions + music + CTA + logo.png 192×192 reveal → export 1080p 16:9 + 9:16 + 1:1 → upload YouTube/TikTok/IG → embed WebM self-hosted in assets/video/ (no CDN per HANDOFF) → update VideoObject schema contentUrl.
